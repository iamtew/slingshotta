# Slingshotta

Fly a ship past planets. Graze the ring for a boost. Aim too steep and you bounce off slower. Hit the body and you crash.

## Play

From this folder:

```
npx serve .
```

Open the URL it prints. Keyboard, mouse (hold and drag), or a gamepad.

W / S thrust. A / D or arrows yaw.

## GitHub Pages

Repo root is the site. Relative URLs, so a project site works.

Settings, Pages, deploy from the branch that has `index.html` at the root.
